# Project agent instructions

## Design and motion

- Before reviewing or changing any visual interface, layout, interaction, accessibility, or UX, read and apply the installed `web-design-guidelines` skill.
- Before reviewing or changing any animation, transition, easing, timing, scroll reveal, hover motion, or motion performance, read and apply the installed `web-animation-design` skill.
- These skills are mandatory for the matching work. Do not rely only on remembered guidance; read their current `SKILL.md` files each turn before editing.
- Keep this portfolio dependency-free unless the user explicitly approves a framework or runtime library. Prefer semantic HTML, CSS, and minimal browser JavaScript.
- Preserve and verify `prefers-reduced-motion` behavior for every animation change.
